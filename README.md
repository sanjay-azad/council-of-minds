# Council of Minds

The Next.js app lives in the `council-of-minds/` subdirectory.

## Quick start

From the **repo root**:

```bash
npm install
npm run dev
```

Or from the app directory directly:

```bash
cd council-of-minds
npm install
npm run dev
```

Copy `council-of-minds/.env.example` to `council-of-minds/.env.local` and add your API keys.

See [council-of-minds/README.md](council-of-minds/README.md) for full documentation.
